# 银龄 AI

> 项目档案卡格式：问题 → 我的角色 → 做了什么 → 结果 → 学到什么 → 证据。
> 新建项目时复制 `_template.md`。

## 一句话

给 65 岁以上用户设计的语音助手，目标是让"不敢按错"的人敢开口。

## 问题

老年人不是不会用智能手机，是**怕用错**。一次误操作（比如误扣费、误删）的代价，对他们远高于年轻人。现有语音助手的问题是：话太多、确认太多、失败时只会说"抱歉我没听懂"。

## 我的角色

产品负责人：定义交互、写提示词、搭评测集、主持用户测试。团队 5 人（2 工程师、1 语音算法、1 运营、我）。

## 做了什么

1. **一次只问一个问题**：把多轮澄清压成单轮，首次响应字数从 62 字降到 17 字。
2. **失败时给出口**：不说"没听懂"，改说"我没听清，你可以说'再说一次'，或者按屏幕上的绿色按钮"。
3. **方言兜底**：识别置信度低于阈值时，自动切到"人工代接"流程。
4. **评测集**：320 条真实老人提问，覆盖 12 类表达方式，每次发版必须全跑。

## 结果

| 指标 | 上线前 | 上线后（6 个月） |
|---|---|---|
| 首次使用成功率 | 43% | 71% |
| 单次会话平均时长 | 4.2 分钟 | 2.6 分钟 |
| NPS | — | 61 |
| 服务家庭数 | 200 | 12,000 |

## 学到什么

1. **老年人的"慢"是谨慎，不是迟钝。** 交互要给他们"反悔"的机会，而不是催他们快。
2. **减少确认比增加确认更安全。** 我们的误操作率在高频确认下反而更高——因为用户形成了"看到就问就点"的习惯。
3. **评测集比模型更重要。** 换过一次模型，指标没动；改了一版评测集，发现 40% 的失败集中在 3 类提问上。
