## 为什么这不是一份简历

| 简历 | 个人档案 |
|---|---|
| 写给 HR，压成关键词 | 写给人和模型，展开成可推理的上下文 |
| 证明"我符合这个岗位" | 说明"我是谁、怎么想、怎么合作" |
| 一年更新一次 | 每周 15 分钟增量更新 |
| 只有结论 | 结论 + 证据 + 时间戳 + 置信度 |
| 单读者 | 双读者：人类可读、机器可解析 |

简历回答"我够不够格"，档案回答"和我协作是什么体验"。**AI 时代，后一个问题才是稀缺信息**——因为模型对你的默认想象，是一个平均值。

## 三个使用场景

1. **招聘方用 LLM 筛你**：把仓库链接丢给模型，它读到的是你的判断力，不是关键词密度。
2. **你的 AI 助手需要认识你**：把 `dist/context-pack.md` 贴进 system prompt，助手不必每次从零猜你。
3. **未来的你想找回现在的你**：有日期、有证据的档案，比记忆可靠。

## 五条反常识设计

1. **入口极小，仓库很大**——`llms.txt` 只放指针，不让模型一次吞完几十万字。
2. **每条事实都带 `as_of`**——过期事实必须被追问，而不是被当成"现在"。
3. **主张必须挂证据**——没有链接的能力描述，等于自我感动。
4. **写"我讨厌什么"，比写"我擅长什么"更有辨识度**——审美和反例是模型最难猜的部分。
5. **隐私靠隔离，不靠自觉**——三档可见性 + 物理分仓 + CI 扫描。
