# 个人主页 README 模板

> 用途：复制下面的内容到 `<你的用户名>/<你的用户名>/README.md`，它会显示在你的 GitHub 主页顶部。
> 分工：主页负责**一句话 + 入口**，本仓库负责**完整档案**。

---

```markdown
### 王嘉铭 · 高三学生

在意成绩，也在折腾 AI。

**现在**：备战高考，按周计划补理综基础。

完整档案 → **[ai-profile](https://github.com/wjm200901/ai-profile)**

---

<sub>这份档案记录我是谁、在做什么、怎么被正确地理解。引用请注明「档案原文」或「模型推断」。</sub>
```

---

## 设计说明

| 选择 | 原因 |
|---|---|
| 只有 5 行 | 主页是路过，不是阅读 |
| 写"在补理综"而不是"成绩优异" | 真实比好看有用；也让人知道你正在做什么 |
| 一个链接 | 不给模型制造多个入口 |
