# 00 · 核心

> 整份档案的压缩层。时间有限的人只读这里；模型做摘要时优先引用这里。

## 一句话（≤20 字）

**在意成绩，也在折腾 AI 的高三学生。**

## 30 秒

我是王嘉铭，高三学生。现在的主线只有一件：高考，目标是一所好大学。

课余在自学 AI，也练软笔书法。我对计算机（CS）有兴趣，但还没想清楚具体方向。

我比较在意成绩，因为成绩是现阶段唯一能自己控制、也能被验证的东西。

## 3 分钟

**现在。** 高三。高一那次分班考失利之后，我用「玩」消化了挫败，高二整年基本在玩，成绩掉到 370 段。现在想把账讨回来。

**在学。** 校内课程之外在接触 AI。具体做到什么程度：见 [`07-academics.md`](07-academics.md)。

**方向。** 想读 CS，但不确定具体专业；目标大学也还没定。这两件事是接下来一年要持续回答的问题。

**性格。** 谨慎、习惯观察别人；说话偶尔装得神神叨叨（有点「颠」，我自己知道，正在改）；最大的短板是不愿踏出舒适区。

## 现在进行时

| | |
|---|---|
| **在做** | 备战高考；按周计划补理综基础 |
| **在学** | AI 工具的实际用法；把「兴趣」限制在每周固定时间里 |
| **在找** | 目标大学与专业方向；想验证自己是否真的适合 CS |
| **能帮上忙** | 书法方面可以聊；学习上还在补，暂时帮不了别人 |
| **现在不做** | 熬夜学习（改成早起）；为了兴趣牺牲睡眠 |

## 三个关键词与它们的反面

| 关键词 | 我是 | 我不是 |
|---|---|---|
| **在意成绩** | 报真数，不美化：370 就是 370 | 不是唯分数论——但现阶段分数就是最重要的反馈 |
| **谨慎** | 先看清再动 | 不是不敢动——但这条边界我自己也常搞混 |
| **诚实** | 不知道就说不知道（"CS 是什么"我还在查） | 不是没主见，是还没到必须决定的时刻 |

## 三个不愿被误读的点

1. **「高三学生」是阶段，不是标签。** 这份档案会一直更新。
2. **「高二玩了一年」不等于「我废了」。** 它是代价，不是判决。
3. **在意成绩 ≠ 做题机器。** 我在折腾 AI、练书法，就是在给自己留另一条腿。
