# 07 · 学业现状与目标

> 本文件是「学业规划」的地基：把现状、目标、差距写成数字，而不是感觉。
> 数据来源：本人自述（2026-11）。标「估」的是推算，不是官方成绩单。

## 现状（2026-11）

| 科目 | 当前 | 满分 | 得分率 | 备注 |
|---|---|---|---|---|
| 语文 | 90+ | 150 | ~60% | 估 |
| 数学 | 110+ | 150 | ~73% | 相对最好的一科 |
| 英语 | 90+ | 150 | ~60% | 估 |
| 物理 + 化学 + 生物 | < 100 | 300 | < 33% | 最大缺口 |
| **总分** | **370+** | **750** | **~50%** | 估 380–390 |

## 目标

| 档位 | 分数 | 含义 |
|---|---|---|
| 保底 | 480 | 本科线附近（需按本省实际线校准） |
| 目标 | 540 | 较好本科 |
| 冲刺 | 600+ | 好大学 |
| 理想 | 623 | 本人设定的方向 |

## 差距（诚实版）

380 → 623 是 **+243 分 / 约 7 个月**。按月算是每月 +35 分，而且越往后越难。

结论：**623 是方向，不是承诺。** 先把 480 打穿，再谈 540。

## 优先级（按"同样努力换多少分"排序）

1. **理综**：300 分只拿到不到 100，说明基础概念大面积缺失，不是不会做难题。基础题 + 选择题 + 大题第一问，是最容易回收的分数。
2. **英语**：90 → 110，词汇、听力、作文模板，提分路径最确定。
3. **语文**：90 → 105，默写、文言实词、作文结构。
4. **数学**：110 → 120，选填不失误 + 前两道大题。性价比低于前三项，但不是不学。

## 时间规则（针对"兴趣来了才学"）

- **固定开始时间，不靠状态。** 到点就坐下，先做 10 分钟最简单的题启动。
- 记录三件事：完成天数 / 总题量 / 错题数。不记录"感觉"。
- 每周留 2 小时「AI 兴趣时间」当奖励，其余时间全部给提分。

## CS 是什么（待验证）

- **CS（计算机科学）**：研究"计算"本身——算法、数据结构、系统、理论，偏数学与逻辑。
- **软件工程**：偏"怎么写好大型软件"。
- **人工智能**：CS 的一个方向（机器学习）。
- 验证方式：每周 1 次、限时 2 小时——用 Python 写 20 行解决一个小问题 / 看一门入门课的前 3 节 / 做 1 道算法入门题。记录"解出来时是爽还是烦"。
- **高三期间不投入超过 2 小时/周。**

## 作息（2026-11 自述）

| 项 | 情况 |
|---|---|
| 工作日 | 6:30 起，约 00:50 睡（睡眠 ≈ 5 小时 40 分） |
| 周六 | 下午 17:20 放学 |
| 周日 | 19:00 到校自习至 22:00 |
| 周末 | 可能 4–5 点睡，白天补觉 |

**关键风险：长期睡眠不足。** 睡眠不足会直接削弱记忆巩固与自控力——这解释了两件事：学不进去，和周末控制不住想玩。


## 时间现状（2026-11 自述）

| 项 | 情况 |
|---|---|
| 每天可支配时间 | 几乎全天（学校作业基本不写） |
| 最大风险 | 不是"没时间"，是**没有结构**：无外部约束 + 兴趣驱动 |
| 周末 | 控制不住想玩（很可能是平时无节奏导致的报复性放松） |
